This is a hexagon based game for the MEGA65. Since I don't know the MEGA65 well I will write it
as a C64 game with VIC-II graphics, but use the increased CPU speed and the blitter to increase
performance. The game will use hires multicolor mode, and blit/copy tiles into the playfield
as needed. The tiles are based on graphics from Freeciv, which is converted to Koala Painter
format using Multipaint. I will try to use a mix of Basic and assembler, where assembler
is taking care of music and graphics, and the game logic is written in Basic 2. The
game will use exomizer and the c65toc64 wrapper to allow the game to be loaded from
C65 mode, then switch to C64 and execute the basic part from there, with the assembler 
installed in its proper location.
